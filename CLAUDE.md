# CLAUDE.md

## Project Rules

1. Always use semantic HTML elements such as `<main>`, `<section>`, `<form>`, and `<label>`.

2. Every form must include client-side validation with clear inline error messages shown below the relevant field.

3. Write responsive CSS using a mobile-first approach before adding desktop styles.

4. Keep JavaScript simple, beginner-friendly, and well commented.

5. Test every feature manually before considering it complete, and review AI-generated code instead of accepting it without verification.
